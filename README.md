# Loan Approval Prediction

## Overview
Machine Learning project to predict loan approval status using applicant details.

## Objective
Build an automated system for loan approval prediction using ML.

## Dataset

## Workflow
- Data Collection
- Data Preprocessing
- Label Encoding
- Train/Test Split
- Model Training
- Evaluation

## Models Tested

- KNN
- SVC
- Logistic Regression
